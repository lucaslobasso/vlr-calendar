# Store listing

## Name
VLR Calendar

## Short description (Chrome Web Store, max 132 chars)
Add individual VLR.gg Valorant matches to Google Calendar with one click.

## Long description
VLR Calendar adds a small "Add to Google Calendar" icon next to upcoming matches on vlr.gg.

- Works on match pages, match lists and brackets
- One click opens Google Calendar with a prefilled event: a short title like "FLY vs NV - Americas", the full team and event names, the right length for Bo1/Bo3/Bo5 and a link back to the match
- Times are converted correctly to your own timezone by Google Calendar
- No account, no permissions, no tracking

Add only the matches you care about, instead of subscribing to a whole feed.

Not affiliated with VLR.gg or Riot Games.

## Categories
- Chrome Web Store: Productivity
- AMO: Other (alternative: Social & Communication)

## Single purpose (CWS)
Add a button to upcoming matches on vlr.gg that creates a Google Calendar event for that match.

## Permission justification (CWS)
The extension requests no API permissions. It accesses vlr.gg only through a content script declared with host matches `https://www.vlr.gg/*` and `https://vlr.gg/*`, to read match details and insert the button. It does not use remote code. Data collection: none.
